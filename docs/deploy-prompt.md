# 部署提示词（交给 AI agent 用）

把下面整段贴给一个能读写本地文件、能执行命令的 AI agent，它就能把这套东西在本机跑起来。

---

## 任务

在本机部署并验证一个「刷题单页 + 本地 LLM 助教」工程。

仓库：<你的仓库地址>
技术栈：单文件 HTML + 原生 JS/CSS，Python 3 标准库（构建与代理），无 npm、无打包。

## 步骤

1. 克隆仓库到一个空目录，进入该目录。
2. 检查 python 版本（需要 3.8+）：python --version
3. 构建页面：python src/build.py
   - 期望输出：已生成 题库.html / 课程: 示例课程 | 题数: 8 | 章节: 2
   - 若报「构建失败: …」，按提示修 data 里的数据，不要去改 build.py 的校验。
4. 用默认浏览器打开 题库.html（file:// 即可，不需要起服务）。
5. 验收做题功能：
   - 第一题应显示 HTTP is a stateless protocol.
   - 点选项应有对错反馈与解析。
   - 顶部计数应随翻页变化。
   - Q 键应切换中英对照，Ctrl+, 应折叠左侧筛选栏。
6. 可选：验证 LLM 助教。
   - 启动代理：python 题库服务.py（会占用 127.0.0.1:8765）
   - 页面右侧按 Ctrl+. 打开助手，⚙ 里填 API 地址、Key、模型。
   - 输入任意问题，能收到回复即视为通过。
   - 若页面提示跨域或连不上，说明代理没起或端口被占用。

## 约束

- 不要修改 data/course.sample.json 里的题目内容，那只是格式示例。
- 不要在仓库里写入 API Key 或其它私有信息。
- 不要为了「跑通」而删掉 src/build.py 里的校验逻辑。
- 构建脚本只用 Python 标准库，不要引入第三方依赖。

## 验收标准

- python src/build.py 成功退出，生成 题库.html
- 双击 题库.html 能作答、能切换中英与深色、进度刷新后仍在
- 需要聊天时，python 题库服务.py 能起在 8765，页面能收到模型回复

## 常见故障

- 端口被占用：题库服务.py 会打印「端口 8765 已被占用」，先关掉旧进程
- 聊天 403：上游账号被限制，换 workbuddy-ai 前缀的同名模型，或换自己的 API
- 聊天返回空正文：思考型模型把额度烧在推理上，把「思考深度」设为 low，或调大 max_tokens
- 页面空白：构建时占位符没被替换，检查是否用 build.py 生成而不是直接改模板
