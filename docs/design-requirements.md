## 一、一句话说清

一个离线可用的**单页刷题工具**，270 道英文选择题，学生考前连做 50–100 题。设计目标只有一个：**长时间盯着不累，答完立刻知道对错**。

## 二、用户与场景

| 项 | 内容 |
|---|---|
| 用户 | 大三学生，操作系统课，期末英文卷 |
| 时段 | 考前 1–3 天，一次连续 40–90 分钟 |
| 设备 | Windows 笔记本为主（，偶尔手机 |
| 环境 | 白天图书馆 / 深夜宿舍（**深色模式使用率很高**） |
| 行为 | 快速翻题，错了看一眼解析就走，不留恋 |

## 三、页面结构（单页，三段）

    ① 顶部     标题 + 统计行 + 主题切换
    ② 工具栏   筛选组 ×3 + 开关 ×3
    ③ 题卡     元信息 → 题干 → 选项 → 反馈 → 操作


## 四、组件清单与状态

### 4.1 筛选按钮（Chip）

- 三组：**题库来源**（全部 270 / 真题 209 / 预测 61）、**章节**（全章 / 第1章 / 第2章 / 第3章）、**题型**（全部 / 判断 / 单选 / 多选）
- 状态：默认、悬停、选中、按下
- 选中用实心填充，未选用描边，两者**尺寸不能变**（避免布局跳动）

### 4.2 选项行（最重要的组件）
**关键**：答对的项和答错的项要**同时可见**（不是只显示对错之一），用户要能对比自己错在哪。

### 4.3 反馈条

- 出现在选项下方，含两行：**✓ 正确 / ✗ 错误　答案：B**、解析文字（中文 20–80 字）
- 正确与错误各一套配色；不要只用颜色，标题里带符号

### 4.4 统计行

**已做 37 / 270 题 · 正确率 86% · 错题 5**

数字比标签重（font-weight 600），一行放得下，375 宽可换行。

### 4.5 空状态

两种文案：**这组筛选下没有题目了** / **错题已清空**。居中，弱化，配一个极简插画或图标。

### 4.6 主题切换

右上角圆形按钮，☾ / ☀ 二态。浅色与深色都要出稿。

## 五、内容约束（设计必须扛得住）

| 元素 | 约束 |
|---|---|
| 题干 | 英文，1–3 行，最长约 120 字符；含空白下划线、引号、括号、I/O 这类斜杠词 |
| 选项 | 2–5 个，单个最长约 90 字符，会折成 2 行 |
| 解析 | 中文，20–80 字，可能含英文术语 |
| 标签 | 真题 / 预测、第 N 章、判断 / 单选 / 多选 |
| 键盘 | 1–9 选选项、Enter 下一题 → **需要可见的焦点态** |

## 六、设计约束

1. **双主题必交**：浅色接近 #ffffff 底，深色接近 #16181c 底，两套都要能读 30 题不刺眼
3. **对比度**：正文 ≥ 4.5:1，深色模式同样满足
4. **无障碍**：对错不能只靠颜色 —— 徽标 + 边框 + 底色三重编码
5. **动效克制**：≤150ms，只做底色与边框过渡，不做位移与缩放
6. **字号基线**：题干 16 / 选项 15 / 解析 14 / 元信息 12

## 七、现状参考（可以推翻）

现有实现用的是白色莫兰迪：主色 #8fa39b、错误色 #b08e8e、边框 #ece8e3、正文 #4b4a47，圆角 8–12px，卡片无阴影只留 1px 边框。
这只是"能用"，不是"好看"，**欢迎重做整套配色与排版**，只保留交互结构。

## 八、交付物

1. **Figma 文件**，四页：
   - Page 1 组件库（Button / Chip / Option / Feedback / Tag / Progress）
   - Page 2 浅色全页（做完题、答对状态）
   - Page 3 深色全页
   - Page 4 状态集合（空状态、多选已选未提交、答错带解析、只看错题）
2. 组件变体命名规范（如 Option/Correct、Option/Wrong-Picked）
3. 标注：间距、字号、行高，以及导出的 **8 个颜色 token**（供直接写进 CSS 变量）
4. 2x PNG 预览图；如有图标，附 SVG
5. 可选：关键动效说明（时长 + 缓动曲线）

## 九、验收标准（三条）

1. 深色模式下连续读 30 题，眼睛不酸；浅色模式在白天屏幕亮度 60% 下不刺眼
2. 375px 宽打开，题干与选项都完整可见，无横向滚动
3. 把截图转成灰度，仍能一眼分出"我选的"和"正确的"（靠图标与边框，不靠红绿）
