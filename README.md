# 题库 · Question Bank

一个纯前端的刷题单页，附带本地 LLM 助教。单文件、离线可用，构建脚本只用 Python 标准库。

## 特性

- 270+ 题量无压力：单文件内嵌数据，打开即用，零网络请求
- 三种题型：判断 / 单选 / 多选，支持多选提交
- 中英对照：可开关，中文译文比英文淡一档
- 深色模式：跟随系统，可手动切换并记住
- 沉浸式布局：左右侧栏挤压式展开，题目列始终居中
- 进度本地保存：已答、正确率、错题、已掌握、收藏、每日练习量
- 错题重练：独立会话重做错题，答对标记「已掌握」并移出错题池，原错误记录保留
- 打乱重练：把当前筛选的题重新洗牌再刷一遍，不覆盖历史记录
- 学习统计：章节 / 题型正确率进度条 + 近 14 天作答柱状图
- 右侧 LLM 助教：解释答案、出同类题；Ctrl+/ 一键插入当前题目
- 键盘操作：1-9 选项、Enter 提交、左右方向键翻页

## 目录

    os-question-bank/
    ├─ 题库.html              构建产物，双击即可打开
    ├─ 题库服务.py            本地代理（聊天功能必需）
    ├─ 启动题库服务.vbs       双击静默启动上面的服务
    ├─ src/
    │   ├─ template.html      页面模板（含全部 CSS/JS，两个占位符）
    │   └─ build.py           把数据注入模板，生成 题库.html
    ├─ data/
    │   ├─ course.sample.json 示例数据（8 题，通用知识，不含任何真实题目）
    │   └─ IMPORT.md          题目导入规范
    └─ docs/
        ├─ design-requirements.md  界面需求
        ├─ tokens.json             设计令牌（颜色/圆角/动效）
        └─ deviations.md           实现与设计稿的偏差记录

## 快速开始

构建（用示例数据）：

    python src/build.py

换成自己的题库：

    python src/build.py data/my-course.json

然后双击 题库.html。

需要 AI 助教时：

    python 题库服务.py

它会在 127.0.0.1:8765 起一个只做反向代理的服务，并打开页面。页面本身仍用 file:// 打开，这样做题进度和以前是同一份。

## 快捷键

| 键 | 作用 |
|---|---|
| 1-9 | 选择选项 |
| Enter | 多选提交 / 下一题 |
| ← → | 上一题 / 下一题 |
| Q | 中英对照 |
| W | 随机顺序 |
| E | 只看错题 |
| T | 错题重练 / 退出重练 |
| S | 学习统计 |
| R | 收藏当前题 |
| Ctrl + , | 开关左侧筛选栏 |
| Ctrl + . | 开关右侧助手 |
| Ctrl + / | 把当前题目放进输入框 |

## 数据

示例数据 data/course.sample.json 只有 8 道通用示例题，用于演示格式，不含任何真实课程题目。导入自己的题库见 data/IMPORT.md。

## 关于 LLM

页面默认指向 http://127.0.0.1:3425/v1（本地 OpenAI 兼容网关），API Key 和模型名留空，首次使用在右侧面板的 ⚙ 里填。

浏览器不允许跨域访问没有 CORS 头的接口，所以聊天请求统一经 题库服务.py 反代到 /v1；这也是为什么聊天必须开着那个服务。做题不需要。

模型带 thinking 时建议把「思考深度」设成 low，否则容易把 token 烧在推理上、正文返回空。
